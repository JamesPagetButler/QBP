**AC1 text:** *Formalize the proposed chain's first link (locale-from-condensed for the relevant spatial case) to a reviewable standard — extend beyond the Cantor-set anecdote toward a forcing argument for ℝ.*

**One-line result:** the spatial first link is a two-line corollary of library facts (ℝ included), so the Cantor anecdote was never load-bearing. The algebra itself supplies the measure on S¹⁴ — the Cayley–Dickson norm N(s) = s s̄ is a positive-definite quadratic form at every doubling level, and a quadratic form determines a volume form; within the class of measures induced by Aut(𝕊)-invariant *quadratic forms*, the S₃ factor of Aut(𝕊) = G₂ × S₃ leaves **exactly one** alternative parameter (μ, the weight of the ℓ-axis; N is μ = 1) — but a *general* Aut-invariant initial measure is any S₃-invariant density on the 3-dimensional orbit space, and only N itself is algebra-supplied. Using N's surface measure as the *initial ensemble* is a MaxEnt-type modelling assumption (Jaynes), not a theorem. What the algebra does **not** supply is the **dynamical rule**: two algebra-compatible rules on the same N-measure give different vacuum statistics (gradient-flow quench ⟨b₀²⟩ = 0.146; Gibbs anneal β → ∞ ⟨b₀²⟩ → ≈ 1/3, `gibbs_check.py`), and nothing in a frame or a condensed set distinguishes them. **Recommendation unchanged: AC2 not met by the condensed/locale route (Prop 12, now an ARGUMENT with one beekeeper crux, not a theorem).**
