## 1. Inclusion rule (AC1 scope, mechanical)

An `anchors[]` record is **numeric** iff at least one top-level field **other than** the bookkeeping fields `tier`, `sorry_count`, `pa_local`, `pa_effective` holds a number (int/float, never bool) or a non-empty list/dict whose leaves are all numbers. String-typed numbers do not count (the schema types `measured_value`/`predicted_value` as `number`).

Why this and not "has `measured_source`": the issue's scope is anchors that *cite agreement with an external convention or measurement*. A field test on `measured_source` would miss records that carry the external number in `measured_value` with the citation in prose (`OBS-jades-gs-z14-0-vrot-lower-100`) and would include nothing the numeric test misses. The numeric test is the superset; rows with no external reference on record say so in the table (`— (none on record)`), so completeness is visible rather than filtered.

Fields observed carrying numbers (ledger 6.19.0): `predicted_value` (77), `measured_value` (78), `measured_error` (68), `discrepancy_pct` (39), `predicted_value_lo` (2), `predicted_value_hi` (1), `predicted_values` (1, dict), `F_max_value` (1), `prediction_at_z_14` (1), `synthetic_separation_sigma` (1).

## 2. Tag rules (first match wins; each cites a record field, never a physics judgement)

| Rule | Condition (record fields) | Tag | Why this is record-mechanical |
|---|---|---|---|
| **R-FIT** | `independent: false` **or** id prefix `FIT-` | SELECTED | the record declares itself a fit |
| **R-OVR** | id in the override table (§3.2) — a **verbatim quote** of a record field, verified at run time (drift = hard error) | per table | the quote *is* the record saying "scanned / best-fit / calibrated INPUT / analytic proof / IDENTIFICATION not prediction" |
| **R-INST** | the transitive `prediction_chain` closure reaches a free-parameter node: an `inputs[]` id (`INST-f0`, `INST-theta`, `INST-TcJ-ratio`, …), an `INST-` anchor, or an R-OVR-SELECTED anchor | SELECTED | `prediction_chain` is the ledger's own dependency edge (`pa_effective` is min over it, `docs/cth/qbp-local-extensions.md`); a fitted input upstream = a degree of freedom exercised. dof per anchor = distinct parameters reached |
| **R-EXT** | `prediction_chain: []` **and** `provenance_kind ∈ {experiment, theory-external}` | FORCED | the number is imported; no QBP degree of freedom is exercised in the record |
| **R-MEAS** | has `measured_value` and **no** predicted-side field (`predicted_value[_lo/_hi/s]`, `prediction_at_z_14`, `F_max_value`) | FORCED | external measurement only — nothing QBP-side to be forced or selected |
| **R-THM** | `provenance_kind: proof`, `lean_theorem`, `sorry_count: 0`, `verification.result: verified` | UNDECIDED | the theorem forces the *algebraic identity*; whether the *physical identification* was derived or chosen is not on record |
| **default** | otherwise | UNDECIDED | what decides it: a Lean derivation of the number from the chain ⇒ FORCED; a named selection step ⇒ SELECTED |

**Discipline.** "FORCED" here means *no free choice on record* — fixed by a theorem or by an external measurement/theorem. "SELECTED" means *the record itself shows a choice* (a fitted input, a scan over candidates, a calibrated parameter). Nothing is tagged on the strength of what the algebra "should" give. Per #479 AC3 every SELECTED row carries the fixed note **"G₂-trivial: zero independent evidential weight."** — see §5 for which rows the *G₂* mechanism actually applies to (none) versus which are fitted inputs (all 28).
